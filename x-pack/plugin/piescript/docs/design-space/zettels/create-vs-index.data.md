# Create vs Index

`Shard.write` always uses INDEX (upsert) semantics (`autoGeneratedTimestamp = -1`). CREATE semantics (fail if document exists) requires error handling — the write must return a `Result` indicating success or conflict. Blocked on sum types / result types (see [[result-types.types]]). Future: `Shard.write` takes a mode parameter or two separate builtins (`Shard.create` vs `Shard.upsert`).
